# Hogwarts Legacy gadget palette plan

## Current agreed behavior — 2026-10-22

- Click **left trigger** to toggle the palette open or closed. Holding does not repeat.
- Require the current pawn's `BTS_Biped_TopLevel_C.IsItemWheelAvailable` to allow opening, selecting or creating a held copy. Use the game's progression check rather than character level. Unavailable/missing-service characters keep vanilla trigger and grip input. Refresh availability on fresh relevant input presses and recheck before creation/selection; unlocks work without resetting scripts. Cache only between interactions, invalidate on pawn/reset, and add no idle tick polling. Native scalar output uses a Lua table's `result` field.
- Suppress the trigger's vanilla input only while gadget access is available and `ui.isRemapDisabled() == false`; pass it through unchanged otherwise.
- While open, press **either hand's grip** within 8 cm (about 3.1 inches) of a model's centre to select that gadget and close the palette. When several models are in range, choose the nearest.
- Selection updates the active gadget and HUD without consuming or using an item. Suppress the selecting grip until released to prevent vanilla tap-use.
- Optional `widget_wheel_3D_gesture_based` checkbox appears directly below Potion Wheel only when `widget_wheel_type == 2`. It defaults to false and uses the existing saved config. While enabled, each left-grip press with the wheel closed (or closing) copies the game's currently selected gadget into the left hand. While the wheel is open, no copy is made unless the press selects a wheel item: confirming the selection starts the close, then the same selected-gadget copy path runs immediately. A left grip on empty space or a locked slot does nothing. Right grip retains selection-only behavior.
- Normally the optional copy exists only while left grip is held. `palette.getActiveMesh()` returns its mesh component while active and immediately returns Lua nil on release; game-thread cleanup detaches and destroys the owned actor and liquid. For attachment adjustments, `TOGGLE_GRIP_FOR_ADJUSTMENTS = true` near the top of `palette.lua` temporarily keeps the copy attached after release; the next left-grip press destroys it instead of selecting/copying another item. Set the flag to false to restore hold-only behavior. Copying never consumes inventory. Copies retain the palette's model scale and appearance, including default Invisibility material, and use existing attachment APIs for smooth native hand following. main.lua registers a targeted left-hand attachment function for initial creation (SKT_LeftHand or raw-controller fallback); it skips the full grip-update/wand path. The existing periodic hand callback still supplies the active mesh. Turning off either option, loss of tracking/pawn/actor, menus, pause, cutscenes, level change and script reset remove the copy.
- A grip away from the models leaves the palette open. Grips are reserved for palette interaction while it is open; fresh grips outside it retain their existing behavior.
- Keep the eight approved models and potion liquids with their current tuned scales in the same vertical ring: radius 18 cm, centre 4 inches (10.16 cm) forward from the sampled left hand, facing the sampled head yaw.
- Show inventory quantities for all eight models, including zero, with `libs/widget.Text` in a host created by `widget.createHostWidget`, displayed through one `libs/widgetcomponent.new` instance. Match the original wheel's green (#00FF00), UI_FNT_Body font/Body typeface and size 17. Place each count 2.7 cm right and 6 cm below its model centre. Behind all eight counts, use the native UI_T_AmountFrame black/gold badge at COUNT_BACKGROUND_SIZE = 40 widget pixels, matching the user-approved live preview. Existing widget.Image.new/addToWidget accepts the loaded texture through its texture field; backgrounds and texts share the exact offset and component, with zOrder 998 and 999 respectively. Remove backgrounds on all count-display cleanup and failed builds. COUNT_OFFSET_TOWARD_VIEWER directly sets the shared text plane depth in centimetres (currently user-tuned to 3; 0 is the model plane, positive is toward the viewer, negative is behind). Right/down offsets and scale remain independent; there is no projection compensation or depth cap. Native attachments preserve the offsets as the head translates; no per-frame positioning. The COUNT_* constants control styling and spacing. Read native InventoryManagerInterface.GetCount with the pawn's CharacterID, each gadget ID, standard/don't-care enum values 0, ActorBackpack and None variation. Refresh every 0.5 seconds while open, writing only changed text. After a normal animated close, retain one hidden count component, host, eight labels and eight badges under an independent palette-owned actor. Reattach it to the next ring and refresh inventory, including quick reopen while the previous close animation/effect is still running; first creation writes each count once instead of writing an empty string first. Explicit close, reset, context loss and failed builds destroy owned active/cached widgets; invalid caches rebuild safely. No cache polling is added to idle tick. Neither shared widget library is extended. Isolated quantity/direct-depth/lifecycle checks pass at depths 0, 2, -2, 8 and 40 cm in both grip modes; Reset Scripts activates the saved style for subsequent spawns. The direct-depth change still needs headset review.
- Attach all eight models to one movable actor with a SceneComponent root at the ring centre. Preserve the spawn position/orientation, then attach that root with KeepWorld to a separate zero-offset HMD anchor. The anchor uses `SetAbsolute(false, true, true)` and identity relative transform: it inherits HMD translation but retains fixed world rotation and unit scale. Head turns/tilts cannot rotate or orbit the wheel. No per-frame Lua position updates.
- Use the documented `libs/particles` inline API to create `NiagaraSystem /Game/VFX/UI/Mission_EntryPoint_Beacon/VFX_NS_MissionEntryPoint_Location.VFX_NS_MissionEntryPoint_Location`: `particles.new(...)`, instance `attachTo(root)`, and instance `destroy()`. Preserve the user's current effect tuning: scale `{.14,.14,.14}`, rotation `{90,0,0}`, location `{5,0,0}`, and natural playback. Destroy the effect and group when closing.
- Grip selection transforms each model's saved local centre through the shared root's current transform, so moving or rotating the group preserves selection alignment. `palette.getActor()` exposes the live parent for later positioning work.
- Rotate every model 90 degrees counterclockwise from its original orientation, viewed from above, about its own centre. Potion liquids rotate with their bottles.
- Close without selecting on menus, pause, cutscenes, pawn replacement, level changes, script reset, or a lost/replaced HMD component. Destroy the palette-owned translation anchor along with the group; never destroy the HMD component.
- Runtime implementation remains in `scripts/helpers/palette.lua`; `scripts/main.lua` requires and initializes it. No production assertions.
- Potion liquid colors are hand-tuned in the `POTION_COLORS` table near the top of `palette.lua`, using linear RGB and per-potion brightness. Edurus is silver, Maxima red, Focus blue, and Thunderbrew purple. The user preferred Invisibility's original material, so it has no color override or exposure compensation. The discarded opaque/glowing experiment and its unused exposure update code have been removed. The user chose code editing instead of sliders. Apply changes with Reset Scripts, then reopen the wheel. The four recolored liquids own separate dynamic materials; bottle decorations and plant materials keep their defaults.
- Liquid visibility repair: preserve the approved `VFX_MM_LiquidBottle_P3D_Adv_maxima` shader, its textures, Tint/Subsurface Color RGB and emissive brightness. Its inherited `Slosh Height = 8.5` clipped the static liquid meshes away in the current location; `STATIC_LIQUID_SLOSH_HEIGHT = -1000000` keeps that cutoff outside the display geometry. Live comparisons with 8.5/0 versus negative values isolated the disappearance to this setting. All four original textured/swirl fills were restored and visually compared with the recovered approved screenshot, including the count labels. The temporary flat MM_Prop replacement was rejected and removed. Invisibility remains on its default material. Reset Scripts activates the saved correction for future wheel spawns.
- Use native UEVR calls for mesh loading, transforms, attachments and selection confirmation. Load palette assets directly by path with getLoadedAsset; never probe dynamic asset names with find_required_object/find_uobject or fall back to a whole-hierarchy scan. Shared uevr_lib remains unchanged. Delegate particle creation and lifecycle to `libs/particles`. The palette has no direct bridge calls: selection matches ItemName across the eight native ItemTop/ItemTR/ItemRight/ItemBR/ItemBottom/ItemBL/ItemLeft/ItemTL object properties, then uses stock confirmation. Cache only a still-valid player-owned gadget service. Existing widget.Text and particle helpers retain their own internal bridge behavior; shared libraries are unchanged.

This replaces the earlier left-grip spawn and hold/stick/release proposals. Stick selection and touch without a grip are outside the current design.

## In-game acceptance checks

- One trigger click opens the ring; another closes it; holding does not repeat or invoke vanilla targeting.
- Trigger input retains vanilla UI behavior when remapping is disabled.
- Grip each model with either hand: ring closes, active gadget and HUD change, inventory does not decrease.
- Keep the selecting grip held, then release: no gadget use. A distant grip must not select.
- Move a hand alone after opening: it does not move the wheel. Move the HMD forward/back/left/right/up/down: the whole wheel follows that translation smoothly. Yaw/pitch/roll must neither turn nor orbit it.
- Move/rotate the shared parent: every model and the attached effect follows; grip selection still matches the moved models.
- Reopen repeatedly and interrupt with menus/level loads/resets: no orphan models, stock widget, or stuck input.
